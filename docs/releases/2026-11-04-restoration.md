# Recovery release — 2026-11-04

The running server had been restored from the older `main` source while its persistent training database retained the newer schema. The lost application was reconstructed from original source-writing commands against the original `v3` base. Recovery scripts, chat history, screenshots, and operational secrets are excluded from this repository.

Restored capabilities:

- Separate authenticated accounts, CSRF checks, admin controls and per-profile data isolation.
- Transactional idempotent set recording, preserved drafts and optional effort fields.
- Calendar-aware descriptive analytics and body measurement comparisons, without invented physiological scores.
- Owned plans, alternatives, per-plan schedules and a consistent evaluator.
- Conservative, time-budgeted generation using available equipment and onboarding preferences.
- First-session guidance, previous-load references, session reviews, and confirmed progression proposals with context checks.
- Voluntary experience feedback with withdrawal/deletion, separate from workout records.
- Two attributed exercise videos previously checked for variant correspondence.

The existing training database is retained in place. Authentication recovery uses existing password hashes for matching profile IDs; no account passwords are published or silently replaced. Preview exercise records are shared catalog metadata; preview training records are synthetic.

Verification includes the functional suite, separate authentication suite, mobile browser journeys and direct database consistency checks. These verify software behavior, not fitness outcomes. Operational evidence and private backup paths are recorded outside the public repository.

Remaining limits: the exercise video library is small, coaching depends on truthful logging, actual technique is not observed, and a consenting human usability/fitness study has not been completed.
