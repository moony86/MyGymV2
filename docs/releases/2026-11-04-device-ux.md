# Personal-device, interface and media update

Installed-app users can keep a remembered session for 90 days with bounded renewal, and valid sessions bypass the login form. Existing signed-in users can remember their device from the account page without retyping credentials. Remembered sessions remain revocable, CSRF protected and bounded to 180 days from issuance. A separate metadata table extends the authentication database without altering existing account rows or training records.

Workout help, plan-completion details, analytics method notes, optional feedback/privacy explanations and secondary home actions are on demand. Actual inputs, saved-state messages, uncertainty markers and pain-related responses remain available. The first set can copy its previous load explicitly without another confirmation dialog. This does not recommend increasing load.

The library now has 12 attributed images and 6 videos across 9 movement types. Newly added clips cover dumbbell lateral raises, machine shoulder press, lying leg curl and leg press. The new clips are compressed to H.264; attribution records describe the transformation and retain source hashes. Media bindings require a reviewed exercise name and equipment match, so ambiguous or incorrectly linked catalog entries do not silently show another apparatus. Coverage remains partial.

Validation: 315 functional tests and 22 security tests passed. Browser checks covered actual Chromium close/reopen with persistent storage, external launcher navigation, compact mobile layout, image loading, H.264 playback, saving a set, library search and remembered-device status. No unhandled JavaScript errors were recorded. Physical Android WebAPK behavior still depends on the app using the same origin and retaining browser data.

No training-history records, goals, plans, analytics formulas or progression rules were changed in this update. Those require separate product/decision review.
